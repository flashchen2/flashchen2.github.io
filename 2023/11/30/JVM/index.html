JVM

一、JVM介绍

  • 定义：Java Virtual Machine - java虚拟机，即java项目通过IDEA编译后，实际运行的地方
  • 好处：
    • 一次编写，到处运行
    • 自动内存管理，垃圾回收功能
    • 数组下标越界检查
    • 多态

1.JVM虚拟机

  1. 整体流程

    1. 通过javac命令，将java文件编译为字节码文件，通过java虚拟机进行运行

      [!NOTE]

      javac 是 Java 编程语言的编译器命令，全称为 “Java Compiler”，它是 Java Development Kit (JDK) 中的一个核心工具

      主要用于将 Java 源代码文件（.java 文件）编译成 Java 字节码文件（.class 文件），这些字节码文件可以在 Java 虚拟机 (JVM) 上运行

    2. 类装载子系统将字节码文件，加载至java虚拟机的内存区域

    3. 字节码执行引擎执行java虚拟机的内存区域的代码

2.内存区域

  • 组成部分：堆、线程栈、本地方法栈、方法区、程序计数器

1.堆

  1. 介绍：用于存储new出来的对象
  2. 线程栈、方法区中的局部变量，都通过指针指向堆中的对象
  3. 内部变化
    1. new出来的对象，会先存储在堆的「年轻代」
    2. 「年轻代」存储满后会执行minor gc，对于缺少引用的对象，将执行垃圾回收
    3. 某个对象存储达到一定时间后，会将其由「年轻代」改放置「老年代」
    4. 「老年代」存储满后会执行full gc，对于缺少引用的对象，将执行垃圾回收
    5. 若堆的所有空间都被存储满，将引发OOM
4. 可以使用jvm自带的诊断工具，jvisualvm进行检查

2.线程栈

  1. 当启动一个线程后，会从线程栈中取出一部分空间，作为运行内存
  2. 线程中的每一个方法，对应线程栈中的每一个栈帧，符合先进后出的逻辑
  3. 栈帧中主要存储了方法的，局部变量、操作数栈、动态链接、方法出口
    1. 局部变量：线程中的变量，随线程销毁而销毁
    2. 操作数栈：供局部变量，进行数据处理的空间
    3. 动态链接：将名称、符号对应的引用，转变为在方法区中的直接引用。例：图中compute()方法，存储在方法区中，线程运行过程中，通过动态链接识别compute()方法所在位置
    4. 方法出口：用于存储返回值

3.本地方法栈

  1. 当本地方法执行过程中，会从本地方法栈中取出一部分空间，作为运行内存

4.方法区

  1. 介绍：用于存储代码中的每一个方法
  2. 组成部分：常量、静态变量、类信息

3.程序计数器

  1. 介绍：用于在线程运行过程中，存储即将运行代码的位置/行号

3.jvm调优目的

  1. 减少项目在full gc过程中，导致的STW (stop the word)，从而引发的用户界面卡顿
  2. 减少机器内存资源开销

二、Arthas

1.介绍

  1. Arthas是阿里在2018年开源的java诊断工具，支持JDK6+，采用命令行交互模式，可以方便的定位和诊断线上程序运行问题

2.常用命令

1.输入dashboard，查看整个进程的运行情况，线程、内存、GC、运行环境信息

2.输入thread，查看线程详情情况

3.输入thread + 线程堆栈，查看线程堆栈

4.输入thread -b，查看线程死锁

3.示例

1.某线程资源占用率100%

  1. dashboard后发现某一线程，持续消耗90%+的CPU资源
  1. command + c退出大盘刷新，输入thread + 线程id，查看线程问题原因
  1. 结合代码行号，查看问题原因。持续while循环，导致资源消耗

2.现成阻塞

  1. dashboard后发现两个线程的状态，都为blocked。猜测可能为相互死锁
  1. command + c退出大盘刷新，输入thread -b，查看线程死锁原因
  1. 结合代码行号，查看问题原因。两个线程加锁循序问题，导致死锁
